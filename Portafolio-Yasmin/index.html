Soy Técnica en Desarrollo de Software recientemente graduada, con formación en desarrollo web, programación orientada a objetos y bases de datos. Me interesa crear aplicaciones funcionales, claras y bien estructuradas, cuidando tanto la lógica como la experiencia del usuario.

Sistema de Ventas - Flia. Chipana

Proyecto académico final aplicado Cliente real Full Stack

Sistema de gestión de ventas desarrollado como proyecto final en las materias de Práctica Profesionalizante y Programación, implementado para un cliente real con el objetivo de digitalizar y optimizar su proceso de ventas.

La aplicación permite administrar productos, clientes y operaciones comerciales, centralizando la información en una plataforma web.

El frontend fue construido con HTML, CSS y JavaScript, mientras que el backend consiste en una API desarrollada en PHP ejecutada en una máquina virtual, con persistencia de datos en una base de datos SQL, garantizando la gestión segura y estructurada de la información.
